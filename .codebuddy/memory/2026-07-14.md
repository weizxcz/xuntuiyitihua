# 2026-07-14

## YHCADLabeller-platfrom 训练流水线排查与修复

### 问题1：选择训练特征崩溃（AttributeError: 'list' object has no attribute 'get'）
- 文件：`function/on_train.py` 的 `_scan_feature_names` / `_resolve_label_index`
- 原因：数据集 json 是**旧格式 list**（`[模型名, {数据}]` 或 `[[模型名, {数据}]]`），代码按新格式 dict 假设调用 `.get()`。
- 修复：新增 `_normalize_label_data(data)` 统一归一化为 dict，两处都先归一化再取 `feature_mapping`。

### 问题2：训练退出码1（ZeroDivisionError: division by zero）
- 日志：`_train_work/_subprocess_train.log`
- 调用栈：`aagnet_train.py` trainer_module → `ema_decay = ... ** (1/iters)`，iters=`len(train_loader)`=0。
- 根因：`dataloader_module()` 中 **train loader 未覆盖 `drop_last`（默认 True）**，而冒烟测试只有 8 个训练样本 < `batch_size=16`，唯一不完整 batch 被丢弃 → loader 长度为 0。
- 修复：
  1. train loader 改 `drop_last=False`（graph 用 dgl.batch，变长 batch 无碍）。
  2. `iters==0` 时抛清晰 RuntimeError 而非除零。
- 注：`divide_train_val_test.py` 之前也修过：小数据集（<3 文件）下 `int(n*0.1)` 会让 val 变 0，已加"每集至少 1 个"的兜底，避免空 val_loader 崩溃。

### 关键事实（跨会话有用）
- 训练子进程：`ai/train_worker.py`（mode=graph/train），真正 traceback 在 `work_dir/_subprocess_{mode}.log`，运行日志在 `work_dir/logs/<特征名>/run_*.log`，路径记录在 `current_log_path.txt`。
- 配置：`ai/AAGNet_train/configs/round_model_config.yaml`，`batch_size=16`、`device='cpu'`、小数据集友好。
- 划分比例硬编码在 `function/on_train.py` generate_graph 的 job_data：8:1:1。
- GUI 提示"训练神经网络失败（退出码1）"来自子进程 `sys.exit(1)`，GUI 未透传 traceback，需读 `_subprocess_train.log` 看真正错误。

- "选择预训练模型"弹窗只写 `round`（圆角）一组：`pretrained_model_round`/`stat_path_round`（main_window.init_ai_env 设置默认路径，指向 ai/AAGNet_infer/weights/）。

### 新增功能：点击"训练神经网络"弹窗填 epochs
- `function/on_train.py` 新增 `TrainEpochDialog`（wx.Dialog + SpinCtrl，默认200，范围1~100000）和 `_update_train_job_epochs()`；`train_model()` 在启动前弹窗，确认后把 epochs 写回 `work_dir/train_job.json` 的 `epochs` 字段。
- `ai/train_worker.py` 在 train 模式把 `job["epochs"]` 设为环境变量 `AAGNET_TRAIN_EPOCHS`。
- `ai/AAGNet_train/aagnet_train.py` 的 `trainer_module()` 优先用 `AAGNET_TRAIN_EPOCHS` 覆盖 yaml 的 `epochs`（作用于循环与 CosineAnnealingLR 的 T_max），非法/非正整数报错。
- 备注：yaml `epochs` 字段仍是默认值来源；用户不弹窗填时走 yaml（graph 模式不读此值）。

- 链路核对：train_tab → function/on_train（主进程，无torch）→ train_client → train_worker（子进程装dgl/torch）→ AAGNet_train 管线。graph 产物路径（processed_data/graph + attr_stat.json）与 trainer_module 读取、train_model 前置校验三者一致 ✓。
