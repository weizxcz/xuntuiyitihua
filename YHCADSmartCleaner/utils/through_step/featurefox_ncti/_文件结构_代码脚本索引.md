## 4. 推理串联（[predict.py](predict.py) —— 两级如何拼起来）

### 4.1 端到端流程

| 阶段 | 行号 | 做的事 | 关键输入/输出 |
|---|---|---|---|
| 入口 | `predict.py:30-60` | CLI 解析 + 加载 STEP | 输入：stp 路径 + 阈值 |
| **第一级推理** | `predict.py:65-90` | `build_face_graph` → `edge_clf.predict_proba` → `calibrator.predict` | 输出：`edge_proba[i]`（每条边） |
| **剪枝 + 连通分量** | `predict.py:95-120` | 阈值剪枝（默认 0.35）→ NetworkX 连通分量 → 候选实例 | 输出：实例列表（每个 = cell_id 集合） |
| **第二级推理** | `predict.py:125-160` | `extract_instance_features` → `inst_clf.predict_proba` | 输出：每实例的 `inst_proba` |
| **拒绝** | `predict.py:165-180` | `inst_proba ≥ 0.80` 才输出 | 输出：最终通槽实例列表 |

### 4.2 关键函数

| 函数 | 行号 | 作用 |
|---|---|---|
| `predict_through_slots(stp_path, edge_thr, inst_thr)` | `predict.py:30-200` | **核心**：端到端单文件预测 |
| `main()` | `predict.py:205-209` | CLI 入口 |

### 4.3 关键阈值（[predict.py:25-28](predict.py#L25-L28)）

```python
DEFAULT_EDGE_THRESHOLD = 0.35   # 第一级剪枝阈值
DEFAULT_INST_THRESHOLD = 0.20   # 第二级接受阈值（与训练时的 0.80 不同，看 predict.py 实际值）
```

> ⚠️ **第二级阈值说明**：训练时拒判阈值 0.80，但推理时接受阈值会更低（更低 = 召回更高）。以代码 `predict.py:25-28` 实际写的为准。
