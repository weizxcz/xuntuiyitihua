# 分组类型参考文档

共 7 个命令

---

## 组名称

**类型：** 建模命令

**说明：** 组名称

**示例：**

```python
doc.RunCommand("cmd_ncti_create_box", "DS_0", 1, 1, 1)
group=NCTI.RootGroup(doc)
group.Name="DS_0"
```

---

## 获取分组

**类型：** 建模命令

**说明：** 获取模型文档中分组信息

**示例：**

```python
group = NCTI.RootGroup(doc)
#获取所有的子分组
allGroup = group.GetAllSubGroup()
print(allGroup)
#获取当前组下的所有的子对象
subObj = group.GetCurSubObject(groupName)
#获取当前组下的所有子分组
subGroup = group.GetCurSubGroup(groupName)
```
