## 获取单元

**类型：** 建模命令

**说明：** 通过单元编号获取单元

**示例：**

```python
#1号单元,确保单元已被成功创建
elem0 = NCTI.MeshElement(1) #通过单元编号获取单元
print(elem0)
elemNodes = elem0.AllNode() #获取单元节点
print(elemNodes)
```
