## 获取最大平面的法向

**类型：** 基础命令

**说明：** 获取最大平面的法向

**示例：**

```python
#选中手机壳模型
doc.Zoom()
sel = NCTI.SelectionManager(doc)
sel.ClearSelected()

#选择表面
view = NCTI.View(doc.ID)
for i in range(6): #六个标准视角全屏框选
    view.SetViewMode(i)
    view.OrbitCamera(0.1,0.2) #微调，该行视情况需要添加
    sel.SelectScreen()

#摆正物体
dir = sel.FindFrontNormal() #获取正面法向
print(dir)
view.Straighten(dir) #摆正
doc.Update()
```

## 重置选择

**类型：** 基础命令

**说明：** 重置选择

**示例：**

