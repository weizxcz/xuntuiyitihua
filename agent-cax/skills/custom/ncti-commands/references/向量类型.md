# 向量类型参考文档

共 2 个命令

---

## 向量

**类型：** 基础命令

**说明：** 实例化一个向量对象，具有X、Y、Z坐标值的属性

**示例：**

```python
vt = NCTI.Vector(1, 2, 3)
val = vt.X
vt.Y += 5
print(val)
print(vt.Y)
```

---

## 获取向量各方向的值

**类型：** 基础命令

**说明：** 获取向量各方向的值

**示例：**

```python
vec = NCTI.Vector(10, 20, 30)
x = vec.X
y = vec.Y
z = vec.Z

print(f"x = {x}")
print(f"y = {y}")
print(f"z = {z}")
```
