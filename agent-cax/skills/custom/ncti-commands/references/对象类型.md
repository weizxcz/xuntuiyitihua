## 获取唯一对象显示名称

**类型：** 建模命令

**说明：** 获取唯一对象显示名称

**示例：**

```python
doc.RunCommand("cmd_ncti_create_box", "b1", 10, 20, 30)
#选中长方体实体对象，创建粒子
sel = NCTI.SelectionManager(doc)
obj = NCTI.Object(doc)
displayNames = obj.GetDisplayName(sel.ObjectNames)

```

## 获取对象

**类型：** 建模命令

**说明：** 获取几何实体对象

**示例：**

```python
doc.RunCommand("cmd_ncti_create_box", "b1", 10, 20, 30)
#选中长方体实体对象，创建粒子
sel = NCTI.SelectionManager(doc)
doc.RunCommand("cmd_ncti_model_create_particle", "particle", sel.ObjectNames, 0.5)
#此处需选中粒子实体对象
sel = NCTI.SelectionManager(doc)
obj = NCTI.Object(doc)
data = obj.GetObjectData(sel.ObjectNames[0])
print(data)
```
