## 根据法向摆正实体

**类型：** 建模命令

**说明：** 根据法向摆正实体

**示例：**

```python
#摆正手机壳示例
doc.Zoom()
sel = NCTI.SelectionManager(doc)
sel.ClearSelected()

#选择表面
view = NCTI.View(doc.ID)
for i in range(6): #六个标准视角全屏框选
    view.SetViewMode(i)
    view.OrbitCamera(0.1,0.2) #微调，该行视情况需要添加
    sel.SelectScreen()

#摆正物体
dir = sel.FindFrontNormal() #获取正面法向
print(dir)
view.Straighten(dir) #摆正
doc.Update()
```

## 设置光源类型

**类型：** 建模命令

**说明：** 设置光源类型

**示例：**

```python
doc.RunCommand("cmd_ncti_create_box", "box1", NCTI.Point(0,0,0), 10, 20, 30)
view = NCTI.View(doc.ID)
# 关闭全部光源
for i in range(8):
    view.SetLightEnable(i, False)
# 打开0号光源
view.SetLightEnable(0, True)
view.SetLightIntensity(0, 100)

view.SetLightType(0, 1, NCTI.Vector(1,0,0))  # 将0号光源调整为屏幕光

view.SetLightType(0, 3, NCTI.Point(30,0,0))  # 或将0号光源调整为点光源
```
