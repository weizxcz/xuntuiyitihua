## 反转

**类型：** 建模命令

**说明：** 根据对象的副本，将所有子形状的方向都颠倒，反转对象的法向

**命令：**

- `doc.RunCommand("cmd_ncti_invert", strObjName)`

**示例：**

```python
doc.RunCommand("cmd_ncti_create_box", "b3", NCTI.Point(7, 0.5, -3), 1, 1, 8)
doc.RunCommand("cmd_ncti_invert", "b3")
```

---

## 圆柱体

**类型：** 建模命令

**说明：** 根据底面半径、高度、下底面圆心所在平面创建圆柱体

**示例：**

```python
pt = NCTI.Point(5, 0, 0)
n = NCTI.Vector(0, 1, 0)
u = NCTI.Vector(1, 0, 0)

# 创建一个底面半径为5，高度为10的圆柱体
doc.RunCommand("cmd_ncti_create_cylinder", "c1", 5, 10)

# 创建一个底面半径为5，高度为10，生成角度为210的圆柱体
doc.RunCommand("cmd_ncti_create_cylinder", "c2", 5, 10, 210)

# 创建一个圆柱底面圆心为(5, 0, 0)，底面半径为5，高度为10的圆柱体
doc.RunCommand("cmd_ncti_create_cylinder", "c3", 5, 10, pt)

# 创建一个圆柱底面圆心为(5, 0, 0)，底面半径为5，高度为10，生成角度为210的圆柱体
doc.RunCommand("cmd_ncti_create_cylinder", "c4", 5, 10, pt, 210)

# 创建一个圆柱底面圆心为(5, 0, 0)，底面半径为5，高度为10，圆柱底面法向为(0, 1, 0)的圆柱体
doc.RunCommand("cmd_ncti_create_cylinder", "c5", 5, 10, pt, n) # 此时局部x轴为全局z轴

# 创建一个圆柱底面圆心为(5, 0, 0)，底面半径为5，高度为10，圆柱底面法向为(0, 1, 0)，生成角度为210的圆柱体
doc.RunCommand("cmd_ncti_create_cylinder", "c6", 5, 10, pt, n, 210)

# 创建一个圆柱底面圆心为(5, 0, 0)，底面半径为5，高度为10，圆柱底面法向为(0, 1, 0)，底面u轴为(1, 0, 0)的圆柱体
doc.RunCommand("cmd_ncti_create_cylinder", "c7", 5, 10, pt, n, u)

# 创建一个圆柱底面圆心为(5, 0, 0)，底面半径为5，高度为10，圆柱底面法向为(0, 1, 0)，底面u轴为(1, 0, 0)，生成角度为210的圆柱体
doc.RunCommand("cmd_ncti_create_cylinder", "c8", 5, 10, pt, n, u, 210)
```

## 圆角

**类型：** 建模命令

**说明：** 通过圆角半径、边ID组成的列表，对实体的边进行倒圆角

**命令：**

- `doc.RunCommand("cmd_ncti_fillet", strObjName, lstRadius, lstEdge)`

**示例：**

```python
#对长方体倒圆角
radius = [1, 1]
doc.RunCommand("cmd_ncti_create_box", "b", 2, 3, 4)
edge = doc.FindEdgeByNearestPoint("b", NCTI.Point(2, 1.5, 0))
edge.extend(doc.FindEdgeByNearestPoint("b", NCTI.Point(2, 3, 2)))
doc.RunCommand("cmd_ncti_fillet", "b", radius , edge)
```
```python
# 选择一条边和倒角半径进行倒圆角

doc.ResetCaseResult()
sel = NCTI.SelectionManager(doc)

if len(sel.CellIDs) < 1 :
    print("请选择边进行倒圆角")
else :
    body = sel.ObjectNames[0]
    edge = sel.CellIDs[0]

    radius = 1.0
    res = doc.ReturnDialogData(-1, "倒角参数", "倒角半径", radius)
    
    if len(res) == 0 :
        print("用户取消了操作")
    else:
        radius = res[0]
        num = len(sel.CellIDs)
        radiusArr = [radius]
        for n in range(1, num):
            radiusArr.append(radius)
        if radius <= 0.0 :
            print("请输入正确的倒角半径")
        else :
            try:
                doc.ResetCaseResult()
                doc.RunCommand("cmd_ncti_fillet", body,radiusArr , sel.CellIDs)    
            except :
                print("请确认倒角半径是否过大 或者 选择的对象是否为边")    
            else:
                print("倒角成功")
```

## 翻转

**类型：** 建模命令

**说明：** 根据几何实体对象名称，反转它的法向

**命令：**

- `doc.RunCommand("cmd_ncti_reverse_normal", strObjName)`

**示例：**

```python
doc.RunCommand("cmd_ncti_create_box", "b", NCTI.Point(-30, -30, -30), 60, 60, 30)
doc.RunCommand("cmd_ncti_create_torus", "s", 20, 10, 90, 180)
#翻转圆环"s"的法向，如果不翻转，会无法进行布尔操作
doc.RunCommand("cmd_ncti_reverse_normal", "s")
doc.RunCommand("cmd_ncti_boolean_unit", "result", "s", "b")
doc.RunCommand("cmd_ncti_delete", ["s", "b"])
```
