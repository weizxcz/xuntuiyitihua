────────────────────────────────────────────────────────
Delete every existing object to start from a clean scene.
Set the length unit to **metres**.

BLOCK 2 – Stage-by-Stage Operations
────────────────────────────────────────────────────────

---  SECTION 1 – Create bed base structure (slats and rails) ---
Create primitive cuboid with size 0.03×0.02×1.9 m and name it slat_0.
Rotate slat_0 so its +Z axis aligns +Z (world).
Align slat_0.XY_face to bed_base.XY_face.
Then move by offset(-0.28, 0, 0).

For i in 1…14:
  Create primitive cuboid with size 0.03×0.02×1.9 m and name it slat_i.
  Rotate slat_i so its +Z axis aligns +Z (world).
  Align slat_i.XY_face to bed_base.XY_face.
  Then move by offset(-0.28 + i·0.04, 0, 0).

Boolean-union slat_0 through slat_14 to form slat_frame; discard individual slats.

Create primitive cuboid with size 0.05×0.05×2.0 m and name it side_rail_long_1.
Rotate side_rail_long_1 so its +Z axis aligns +Z (world).
Align side_rail_long_1.XY_face to bed_base.XY_face.
Then move by offset(0, -0.65, 0).

Create primitive cuboid with size 0.05×0.05×2.0 m and name it side_rail_long_2.
Rotate side_rail_long_2 so its +Z axis aligns +Z (world).
Align side_rail_long_2.XY_face to bed_base.XY_face.
Then move by offset(0, 0.65, 0).

Create primitive cuboid with size 0.05×0.05×1.4 m and name it end_rail_1.
Rotate end_rail_1 so its +Z axis aligns +Z (world).
Align end_rail_1.XY_face to bed_base.XY_face.
Then move by offset(-0.95, 0, 0).

Create primitive cuboid with size 0.05×0.05×1.4 m and name it end_rail_2.
Rotate end_rail_2 so its +Z axis aligns +Z (world).
Align end_rail_2.XY_face to bed_base.XY_face.
Then move by offset(0.95, 0, 0).

Boolean-union slat_frame, side_rail_long_1, side_rail_long_2, end_rail_1, end_rail_2 to form bed_base; discard intermediate parts.
Stage 1 complete.

---  SECTION 2 – Create bed legs ---
For r in 0…1 and c in 0…1:
  Create primitive cuboid with size 0.05×0.15×0.05 m and name it leg_r_c.
  Rotate leg_r_c so its +Z axis aligns +Z (world).
  Align leg_r_c.XY_face to bed_base.XY_face.
  Then move by offset(-0.95 + c·1.9, -0.65 + r·1.3, 0).

Boolean-union leg_0_0, leg_0_1, leg_1_0, leg_1_1 to form bed_legs; discard individual legs.
Stage 2 complete.

---  SECTION 3 – Create headboard ---
Create primitive cuboid with size 0.05×0.8×1.4 m and name it headboard_panel.
Rotate headboard_panel so its +Z axis aligns +Z (world).
Align headboard_panel.XY_face to bed_base.XY_face.
Then move by offset(0, 0, -0.7).

For i in 0…1:
  Create primitive cuboid with size 0.05×1.0×0.05 m and name it headboard_post_i.
  Rotate headboard_post_i so its +Z axis aligns +Z (world).
  Align headboard_post_i.XY_face to bed_base.XY_face.
  Then move by offset(-0.65 + i·1.3, 0, -0.7).

Boolean-union headboard_panel, headboard_post_0, headboard_post_1 to form headboard; discard intermediate parts.
Stage 3 complete.

---  SECTION 4 – Create footboard ---
Create primitive cuboid with size 0.05×0.6×1.4 m and name it footboard_panel.
Rotate footboard_panel so its +Z axis aligns +Z (world).
Align footboard_panel.XY_face to bed_base.XY_face.
Then move by offset(0, 0, 0.7).

For i in 0…1:
  Create primitive cuboid with size 0.05×0.8×0.05 m and name it footboard_post_i.
  Rotate footboard_post_i so its +Z axis aligns +Z (world).
  Align footboard_post_i.XY_face to bed_base.XY_face.
  Then move by offset(-0.65 + i·1.3, 0, 0.7).

Boolean-union footboard_panel, footboard_post_0, footboard_post_1 to form footboard; discard intermediate parts.
Stage 4 complete.

---  SECTION 5 – Assemble frame structure ---
Connect headboard.XY_face to bed_base.XY_face at offset(0, 0, -0.7).
Connect footboard.XY_face to bed_base.XY_face at offset(0, 0, 0.7).
Connect bed_legs.XY_face to bed_base.XY_face.
Boolean-union bed_base, headboard, footboard, bed_legs to form frame_structure; discard intermediate parts.
Stage 5 complete.

---  SECTION 6 – Create bedding (mattress, pillows, duvet) ---
Create primitive cuboid with size 1.4×0.2×2.0 m and name it mattress.
Rotate mattress so its +Z axis aligns +Z (world).
Align mattress.XY_face to bed_base.XY_face.
Then move by offset(0, 0, 0.01).

For i in 0…1:
  Create primitive cuboid with size 0.6×0.2×0.4 m and name it pillow_i.
  Rotate pillow_i so its +Z axis aligns +Z (world).
  Align pillow_i.XY_face to mattress.XY_face.
  Then move by offset(-0.2 + i·0.4, 0, 0.1).

Create primitive cuboid with size 1.4×0.15×2.0 m and name it duvet.
Rotate duvet so its +Z axis aligns +Z (world).
Align duvet.XY_face to mattress.XY_face.
Then move by offset(0, 0, 0.1).

Boolean-union pillow_0, pillow_1 to form pillows; discard individual pillows.
Stage 6 complete.

---  SECTION 7 – Final Assembly ---
Connect mattress.XY_face to frame_structure.XY_face.
Connect pillows.XY_face to mattress.XY_face.
Connect duvet.XY_face to mattress.XY_face.
Boolean-union frame_structure, mattress, pillows, duvet to form bed_frame; discard intermediate parts.
Assembly guideline satisfied.
All stages complete.
