BLOCK 2 – Stage-by-Stage Operations
────────────────────────────────────────────────────────

---  SECTION 1 – Create base plate  ---
Create primitive cuboid with size 0.200×0.020×0.200 m and name it base_plate.
Rotate base_plate so its +Z axis aligns +Z (world).
Align base_plate.XY_face to world origin (0,0,0).
Then move by offset(0, 0, 0.010).
Stage 1 complete.

---  SECTION 2 – Create motor assembly  ---
Create primitive cuboid with size 0.040×0.040×0.050 m and name it stepper_motor.
Rotate stepper_motor so its +Z axis aligns +Z (world).
Align stepper_motor.XY_face to base_plate.XY_face.
Then move by offset(0, -0.050, 0.010).

Create primitive cylinder with Ø0.006×0.150 m and name it lead_screw.
Rotate lead_screw so its +Z axis aligns +Z (world).
Align lead_screw.bottom_face to stepper_motor.top_face.
Then move by offset(0, 0, 0.025).

Create primitive cuboid with size 0.010×0.010×0.010 m and name it nut_block.
Rotate nut_block so its +Z axis aligns +Z (world).
Align nut_block.bottom_face to lead_screw.top_face.
Then move by offset(0, 0, 0.075).
Stage 2 complete.

---  SECTION 3 – Create display module  ---

Create primitive cuboid with size 0.100×0.060×0.002 m and name it lcd_screen.

Create primitive cuboid with size 0.120×0.040×0.002 m and name it control_panel.
Rotate control_panel so its +Z axis aligns +Z (world).

Then move by offset(0, -0.060, 0.005).
Stage 3 complete.

---  SECTION 4 – Create syringe holder  ---
Create primitive cuboid with size 0.150×0.020×0.010 m and name it guide_rail.
Rotate guide_rail so its +Z axis aligns +Z (world).
Align guide_rail.XY_face to base_plate.XY_face.
