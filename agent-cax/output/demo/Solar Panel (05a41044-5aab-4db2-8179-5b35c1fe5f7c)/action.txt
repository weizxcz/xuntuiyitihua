BLOCK 2 – Stage-by-Stage Operations
────────────────────────────────────────────────────────

---  SECTION 1 – Create frame rails  ---
Create primitive cylinder with size Ø0.040×1.600 m and name it frame_top.
Rotate frame_top so its +Z axis aligns +Z (world).
Anchor frame_top to solar_panel.origin.
Then move by offset(0, 0.500, 0).

Create primitive cylinder with size Ø0.040×1.600 m and name it frame_bottom.
Rotate frame_bottom so its +Z axis aligns +Z (world).
Anchor frame_bottom to solar_panel.origin.
Then move by offset(0, -0.500, 0).

Create primitive cylinder with size Ø0.040×1.000 m and name it frame_left.
Rotate frame_left so its +Z axis aligns +X (world).
Anchor frame_left to solar_panel.origin.
Then move by offset(-0.800, 0, 0).

Create primitive cylinder with size Ø0.040×1.000 m and name it frame_right.
Rotate frame_right so its +Z axis aligns +X (world).
Anchor frame_right to solar_panel.origin.
Then move by offset(0.800, 0, 0).

Stage 1 complete.

---  SECTION 2 – Create photovoltaic cell array  ---
For r in 0…5 and c in 0…9:
  Create primitive cuboid with size 0.15×0.15×0.005 m and name it cell_r_c.
  Rotate cell_r_c so its +Z axis aligns +Z (world).
  Anchor cell_r_c to solar_panel.origin.
  Then offset(-0.75 + c·0.15, -0.45 + r·0.15, 0.02).

Stage 2 complete.

---  SECTION 3 – Create junction box and wires  ---
Create primitive cuboid with size 0.080×0.060×0.030 m and name it junction_box_body.
Rotate junction_box_body so its +Z axis aligns +Z (world).
Anchor junction_box_body to solar_panel.origin.
Then move by offset(0.700, 0.700, 0.015).

Create primitive cuboid with size 0.080×0.060×0.005 m and name it junction_box_lid.
Rotate junction_box_lid so its +Z axis aligns +Z (world).
Anchor junction_box_lid to junction_box_body.top_face.
Then move by offset(0, 0, 0.0175).

Create primitive cylinder with size Ø0.020×0.010 m and name it junction_box_connector.
Rotate junction_box_connector so its +Z axis aligns +Z (world).
Anchor junction_box_connector to junction_box_body.top_face.
Then move by offset(0, 0, 0.020).

Create primitive cylinder with size Ø0.005×0.100 m and name it junction_box_wire.
Rotate junction_box_wire so its +Z axis aligns +Z (world).
Anchor junction_box_wire to junction_box_body.top_face.
Then move by offset(0.010, 0, 0.020).

Create primitive cylinder with size Ø0.005×0.100 m and name it junction_box_wire_black.
Rotate junction_box_wire_black so its +Z axis aligns +Z (world).
Anchor junction_box_wire_black to junction_box_body.top_face.

Stage 3 complete.
