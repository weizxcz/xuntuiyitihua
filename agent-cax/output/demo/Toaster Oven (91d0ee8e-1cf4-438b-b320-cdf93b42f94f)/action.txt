BLOCK 2 – Stage-by-Stage Operations
────────────────────────────────────────────────────────

---  SECTION 1 – Create main body shell  ---
Create primitive cuboid with size 0.45×0.30×0.35 m and name it main_body_shell.
Rotate main_body_shell so its +Z axis aligns +Z (world).
Anchor main_body_shell to world origin.
Then move by offset(0,0,0).

---  SECTION 2 – Create main body cavity  ---
Create primitive cuboid with size 0.40×0.25×0.30 m and name it main_body_cavity.
Rotate main_body_cavity so its +Z axis aligns +Z (world).
Anchor main_body_cavity to main_body_shell.center.
Then move by offset(0,0,0).
Boolean-subtract main_body_cavity from main_body_shell; discard main_body_cavity.
Assembly guideline satisfied.
Stage 2 complete.

---  SECTION 3 – Create door frame  ---
