BLOCK 0 – Scene Reset & Units
────────────────────────────────────────────────────────
Delete every existing object to start from a clean scene.
Set the length unit to **metres**.

---

BLOCK 1 – Materials
────────────────────────────────────────────────────────
Define material mat_panel; diffuse_color = (0.85,0.82,0.78,1.0).
Define material mat_pattern; diffuse_color = (0.15,0.15,0.15,1.0).

---

BLOCK 2 – Stage-by-Stage Operations
────────────────────────────────────────────────────────

---  SECTION 1 – Create base plate  ---
Create primitive cuboid with size 1.2×1.2×0.02 m and name it base_plate.
Rotate base_plate so its +Z axis aligns +Z (world).
Anchor base_plate to world origin.
Then move by offset(0,0,0).
Stage 1 complete.

---  SECTION 2 – Create frame rails  ---
Create primitive cuboid with size 1.2×0.05×0.03 m and name it frame_rail_top.
Rotate frame_rail_top so its +Z axis aligns +Z (world).
Align frame_rail_top.bottom_face to base_plate.top_face.
Then move by offset(0,0,0.015).

Create primitive cuboid with size 1.2×0.05×0.03 m and name it frame_rail_bottom.
Rotate frame_rail_bottom so its +Z axis aligns +Z (world).
Align frame_rail_bottom.top_face to base_plate.top_face.
Then move by offset(0,0,-0.015).

Create primitive cuboid with size 0.05×1.2×0.03 m and name it frame_rail_left.
Rotate frame_rail_left so its +Z axis aligns +Z (world).
Align frame_rail_left.right_face to base_plate.top_face.
Then move by offset(-0.575,0,0.015).

Create primitive cuboid with size 0.05×1.2×0.03 m and name it frame_rail_right.
Rotate frame_rail_right so its +Z axis aligns +Z (world).
Align frame_rail_right.left_face to base_plate.top_face.
Then move by offset(0.575,0,0.015).
Stage 2 complete.

---  SECTION 3 – Create hexagonal prism grid  ---
For r in 0…3 and c in 0…3:
  Create primitive hexagonal prism with diameter 0.15 m and height 0.01 m and name it hex_prism_r_c.
  Rotate hex_prism_r_c so its +Z axis aligns +Z (world).
  Align hex_prism_r_c.center to Avg(frame_rail_left.center, frame_rail_right.center, frame_rail_top.center, frame_rail_bottom.center).
  Then offset(dx, dy, 0.015) where dx = -0.45 + c * 0.3 and dy = -0.45 + r * 0.3.
Stage 3 complete.

All stages complete.
