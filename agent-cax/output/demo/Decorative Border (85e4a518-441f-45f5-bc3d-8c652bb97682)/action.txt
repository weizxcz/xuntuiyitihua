BLOCK 0 – Scene Reset & Units
────────────────────────────────────────────────────────
Delete every existing object to start from a clean scene.
Set the length unit to **metres**.

---

BLOCK 1 – Materials
────────────────────────────────────────────────────────
Define material mat_black; diffuse_color = (0.05,0.05,0.05,1.0).
Define material mat_white; diffuse_color = (0.95,0.95,0.95,1.0).

BLOCK 2 – Stage-by-Stage Operations
────────────────────────────────────────────────────────

---  SECTION 1 – Create page_base  ---
Create primitive cuboid with size 0.210×0.297×0.001 m and name it page_base.
Rotate page_base so its +Z axis aligns +Z (world).
Anchor page_base to world origin.
Then move by offset(0,0,0).
Stage 1 complete.

---  SECTION 2 – Create border_frame  ---

Rotate top_strip so its +Z axis aligns +Z (world).
Align top_strip.bottom_face to page_base.top_face.
Then move by offset(0,0,0).
---  SUB-SECTION 2.2 – Create bottom_strip  ---

---  SUB-SECTION 2.3 – Create left_strip  ---

Rotate left_strip so its +Z axis aligns +Z (world).

Then move by offset(0,0,0).
---  SUB-SECTION 2.4 – Create right_strip  ---

Stage 2 complete.

---  SECTION 4 – Create pattern_unit  ---
---  SUB-SECTION 4.1 – Create triangle  ---
Create primitive triangle with side length 0.0127 m and name it triangle.
Rotate triangle so its +Z axis aligns +Z (world).
Anchor triangle to world origin.
Then move by offset(0,0,0).
---  SUB-SECTION 4.2 – Create square  ---
Create primitive cuboid with size 0.0127×0.0127×0.001 m and name it square.
Rotate square so its +Z axis aligns +Z (world).
Anchor square to world origin.
Then move by offset(0.0127,0,0).
Stage 4 complete.

---  SECTION 5 – Apply pattern_top  ---
For i in 0…15:
  Create primitive triangle with side length 0.0127 m and name it pattern_top_triangle_i.
  Rotate pattern_top_triangle_i so its +Z axis aligns +Z (world).
  Align pattern_top_triangle_i.bottom_face to top_strip.top_face.
  Then position at polar(0°; dr=0.105 - i*0.0127).
  Create primitive cuboid with size 0.0127×0.0127×0.001 m and name it pattern_top_square_i.
  Rotate pattern_top_square_i so its +Z axis aligns +Z (world).
  Align pattern_top_square_i.bottom_face to top_strip.top_face.
  Then position at polar(0°; dr=0.105 - i*0.0127 + 0.0127).
Stage 5 complete.
