BLOCK 2 – Stage-by-Stage Operations
────────────────────────────────────────────────────────

---  SECTION 1 – Create PCB Substrate and Base Layer  ---
Create primitive cuboid with size 0.150×0.100×0.002 m and name it substrate.
Rotate substrate so its +Z axis aligns +Z (world).
Anchor substrate to world origin.
Then move by offset(0,0,0).
Create primitive cuboid with size 0.150×0.100×0.00005 m and name it copper_layer.
Rotate copper_layer so its +Z axis aligns +Z (world).
Align copper_layer.+Z_face to substrate.+Z_face.
Then move by offset(0,0,0.001).
Create primitive cylinder with diameter 0.002 m and height 0.002 m and name it via_1.
Rotate via_1 so its +Z axis aligns +Z (world).
Anchor via_1 to substrate.
Then move by offset(-0.05, -0.03, 0).
Create primitive cylinder with diameter 0.002 m and height 0.002 m and name it via_2.
Rotate via_2 so its +Z axis aligns +Z (world).
Anchor via_2 to substrate.
Then move by offset(0.05, 0.03, 0).
Boolean-union via_1 to substrate.
Boolean-union via_2 to substrate.
Boolean-union copper_layer to substrate.
Stage 1 complete.
