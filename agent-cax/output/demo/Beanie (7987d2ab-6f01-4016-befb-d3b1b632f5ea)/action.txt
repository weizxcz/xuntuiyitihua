BLOCK 0 – Scene Reset & Units
────────────────────────────────────────────────────────
Delete every existing object to start from a clean scene.
Set the length unit to **metres**.

---

BLOCK 1 – Materials
────────────────────────────────────────────────────────
Define material fabric_green; diffuse_color = (0.05, 0.25, 0.05, 1.0).

---

BLOCK 2 – Stage-by-Stage Operations
────────────────────────────────────────────────────────

---  SECTION 1 – Create beanie body  ---
Create primitive cylinder with radius 0.110 m and height 0.150 m and name it beanie_body.
Rotate beanie_body so its +Z axis aligns +Z (world).
Align beanie_body.center to world.center.
Then move by offset(0,0,0.025).

---  SECTION 2 – Create beanie crown  ---
Create primitive sphere with radius 0.110 m and name it beanie_crown.
Rotate beanie_crown so its +Z axis aligns +Z (world).
Align beanie_crown.center to beanie_body.top_face.
Then move by offset(0,0,0.005).

Stage 2 complete.
All stages complete.
