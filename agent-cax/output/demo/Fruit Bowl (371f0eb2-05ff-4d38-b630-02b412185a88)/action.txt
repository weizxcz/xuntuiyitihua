BLOCK 0 – Scene Reset & Units
────────────────────────────────────────────────────────
Delete every existing object to start from a clean scene.
Set the length unit to **metres**.

BLOCK 1 – Materials
────────────────────────────────────────────────────────
Define material ceramic_white; diffuse_color = (0.95,0.95,0.95,1.0).

BLOCK 2 – Stage-by-Stage Operations
────────────────────────────────────────────────────────

---  SECTION 1 – Create bowl body  ---
Create primitive cylinder with diameter 0.250 m and height 0.080 m and name it bowl_body.
Rotate bowl_body so its +Z axis aligns +Z (world).
Anchor bowl_body to world origin.
Then move by offset(0,0,0).
Assembly guideline satisfied.
Stage 1 complete.

---  SECTION 2 – Create base foot  ---
Create primitive cylinder with diameter 0.060 m and height 0.010 m and name it base_foot.
Rotate base_foot so its +Z axis aligns +Z (world).
Align base_foot.top_face to bowl_body.bottom_face.
Then move by offset(0,0,-0.005).
Assembly guideline satisfied.
Stage 2 complete.

All stages complete.
