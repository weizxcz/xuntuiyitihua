---  SECTION 1 – Create Base Plate  ---
Create primitive cuboid with size 0.200×0.150×0.010 m and name it base_plate.
Rotate base_plate so its +Z axis aligns +Z (world).
Anchor base_plate to world origin.
Move base_plate by offset(0,0,0).
Stage 1 complete.

---  SECTION 2 – Create Motor Assembly  ---
Create primitive cuboid with size 0.040×0.040×0.040 m and name it stepper_motor.
Rotate stepper_motor so its +Z axis aligns +X (world).
Anchor stepper_motor to base_plate.bottom_face.
Move stepper_motor by offset(0.050,-0.050,0.010).

Create primitive cuboid with size 0.040×0.040×0.040 m and name it motor_mount.
Rotate motor_mount so its +Z axis aligns +X (world).
Anchor motor_mount to base_plate.bottom_face.

Create primitive cylinder with Ø0.010×0.020 m and name it coupling.
Rotate coupling so its +Z axis aligns +X (world).

Connect stepper_motor.right_face + coupling.left_face.
Connect coupling.right_face + lead_screw.left_face.
Stage 2 complete.
