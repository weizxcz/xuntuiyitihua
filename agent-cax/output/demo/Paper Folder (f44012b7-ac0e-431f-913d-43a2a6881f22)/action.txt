BLOCK 2 – Stage-by-Stage Operations
────────────────────────────────────────────────────────

---  SECTION 1 – Create folder base (U-shape)  ---
Create primitive cuboid with size 0.210×0.297×0.005 m and name it folder_base_body.
Rotate folder_base_body so its +Z axis aligns +Z (world).
Anchor folder_base_body to world origin.
Then move by offset(0,0,0).
Create plane_cutter and name it folder_base_cut_1 with size 0.001×0.297×0.010 m; orientation=axis:+X.
Anchor folder_base_cut_1 to folder_base_body.left_face.
Then move by offset(-0.070, 0, 0).
Boolean-subtract folder_base_cut_1 from folder_base_body; discard folder_base_cut_1.
Create plane_cutter and name it folder_base_cut_2 with size 0.001×0.297×0.010 m; orientation=axis:+X.
Anchor folder_base_cut_2 to folder_base_body.right_face.
Then move by offset(0.070, 0, 0).
Boolean-subtract folder_base_cut_2 from folder_base_body; discard folder_base_cut_2.
Create plane_cutter and name it folder_base_cut_3 with size 0.070×0.001×0.010 m; orientation=axis:+Y.
Anchor folder_base_cut_3 to folder_base_body.bottom_face.
Then move by offset(0, -0.1485, 0).
Boolean-subtract folder_base_cut_3 from folder_base_body; discard folder_base_cut_3.
Create plane_cutter and name it folder_base_cut_4 with size 0.070×0.001×0.010 m; orientation=axis:+Y.
Anchor folder_base_cut_4 to folder_base_body.bottom_face.
Then move by offset(0, 0.1485, 0).
Boolean-subtract folder_base_cut_4 from folder_base_body; discard folder_base_cut_4.
Rotate folder_base_body so its +Z axis aligns +Z (world).
Anchor folder_base_body to world origin.
Then move by offset(0,0,0).
Bevel folder_base_body.edges with radius 0.001 m, segments 4.
Assembly guideline satisfied.
Stage 1 complete.
