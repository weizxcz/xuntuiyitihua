────────────────────────────────────────────────────────
Delete every existing object to start from a clean scene.

BLOCK 1 – Materials

BLOCK 2 – Stage-by-Stage Operations

---  SECTION 1 – Create side panels  ---
Create primitive cuboid with size 0.025×1.829×0.305 m and name it side_L.
Rotate side_L so its +Z axis aligns +Z (world).
Anchor side_L to world origin.
Then move by offset(-0.762, 0.9145, 0).
