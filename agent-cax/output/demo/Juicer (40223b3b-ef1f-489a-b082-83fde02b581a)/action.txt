BLOCK 2 – Stage-by-Stage Operations
────────────────────────────────────────────────────────

---  SECTION 1 – Base Housing and Feet  ---
Create primitive cuboid with size 0.15×0.15×0.25 m and name it housing.
Rotate housing so its +Z axis aligns +Z (world).
Move housing to pos=(0,0,0.125).

Create primitive cylinder with size Ø0.02×0.01 m and name it foot_1.
Rotate foot_1 so its +Z axis aligns +Z (world).
Move foot_1 to pos=(0.06, 0.06, 0.005).

Create primitive cylinder with size Ø0.02×0.01 m and name it foot_2.
Rotate foot_2 so its +Z axis aligns +Z (world).
Move foot_2 to pos=(-0.06, 0.06, 0.005).

Create primitive cylinder with size Ø0.02×0.01 m and name it foot_3.
Rotate foot_3 so its +Z axis aligns +Z (world).
Move foot_3 to pos=(0.06, -0.06, 0.005).

Create primitive cylinder with size Ø0.02×0.01 m and name it foot_4.
Rotate foot_4 so its +Z axis aligns +Z (world).
Move foot_4 to pos=(-0.06, -0.06, 0.005).

Boolean-union housing, foot_1, foot_2, foot_3, foot_4; keep housing.
Name the resulting composite object base_plate.
Stage 1 complete.
