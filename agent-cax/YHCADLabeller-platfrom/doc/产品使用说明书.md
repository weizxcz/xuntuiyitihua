# 炎核几何特征识别标注工具 — 产品使用说明书

---

## 一、产品简介

**炎核几何特征识别标注工具（YHCADLabeller）** 是一款面向 CAD 三维模型的几何特征标注软件。用户可以在 3D 视图中直接点选模型的几何面，为其标注特征类型（如圆角、倒角、盲孔、通孔等），最终导出结构化 JSON 数据，供下游 AI 模型训练使用。

### 适用场景

- 为 CAD 模型的几何特征构建训练数据集
- 对 STEP/IGS 格式的 CAD 零件进行语义分割和实例分割标注
- 标注孔、槽等特征的底面信息

### 系统要求

- 操作系统：Windows 10 及以上
- Python 3.x
- 依赖：wxPython 4.2.1
- 需要配置 NCTI SDK（详见配置章节）

---

## 二、快速上手

以下是从导入模型到导出标注的完整操作流程：

```
导入 STEP 模型 → 切换到标注选项卡 → 定义特征名称 → 选择面并标注 → 导出 JSON
```
具体步骤如下：

### 步骤 1：启动程序

```bash
python main.py
```

启动后出现主窗口，中央为 3D 视图区域，顶部为选项卡工具栏。

### 步骤 2：导入 CAD 模型

1. 点击顶部 **「文件」** 选项卡
2. 点击 **「创建零件」** 按钮，在弹出的对话框中确认创建（默认使用 OCC 几何引擎 + GMSH 网格引擎）
3. 点击工具栏中的 **「导入」** 或 **「导入零件」** 按钮
4. 在文件选择对话框中选择 STEP（.stp / .step）或 IGES（.igs）格式的 CAD 文件
5. 确认后模型将在 3D 视图中显示

### 步骤 3：切换到标注模式

1. 点击顶部 **「标注」** 选项卡
2. 左侧自动展开 **「特征名称」** 面板，右侧自动展开 **「标注特征」** 面板

### 步骤 4：添加特征名称

1. 在左侧面板的输入框中输入特征名称（如"圆角"、"盲孔"）
2. 点击 **「添加」** 按钮，名称出现在列表中
3. 在列表中点击选中当前要使用的特征名称（高亮表示已选中）

> 系统会为每个特征名称自动分配一个唯一的数字 ID，导出时用于标识类别。

### 步骤 5：选择面并标注

1. 在 3D 视图中用鼠标左键点击模型的几何面（可按住Ctrl多选）
2. 点击右侧面板的 **「标注」** 按钮
3. 选中的面将被标记为当前特征，标注记录出现在右侧列表中

### 步骤 6：导出标注结果

1. 点击顶部 **「标注」** 选项卡中的 **「导出标注json」** 按钮
2. 选择保存路径和文件名
3. 确认后生成 JSON 标注文件

## 三、功能详解

### 3.1 文件选项卡

**「文件」** 选项卡提供以下操作：

| 按钮 | 功能 |
|------|------|
| 创建零件 | 关闭当前文档，创建新的空白零件文档 |
| 创建装配 | 关闭当前文档，创建新的空白装配文档 |
| 导入零件 | 弹出文件对话框，导入 STP / STEP / IGS 格式的 CAD 文件 |
| 打开 | 打开已保存的 .ncti 工程文件 |
| 保存 | 将当前文档保存为 .ncti 工程文件 |
| 关闭文档 | 关闭当前文档并创建空白新文档 |
| 导出 | 将当前模型导出为 IGS / STP / STEP / BREP 等格式 |

### 3.2 选择/显示选项卡

**「选择/显示」** 选项卡控制 3D 视图的显示和交互模式。

#### 显示模式

控制模型在 3D 视图中的可见元素：

| 选项 | 说明 |
|------|------|
| 体 | 显示完整的体（勾选后自动勾选面、线、点） |
| 面 | 显示模型的表面 |
| 线 | 显示模型的边线 |
| 点 | 显示模型的顶点 |

#### 选择模式

控制鼠标点击时可以选择的元素类型：

| 选项 | 说明 |
|------|------|
| 体 | 允许选中整个体（勾选后自动勾选面、线、点） |
| 面 | 允许选中单个面 |
| 线 | 允许选中边线 |
| 点 | 允许选中顶点 |

> **标注时建议**：保持「面」勾选、取消其他选项，这样可以精确选择单个几何面。

### 3.3 标注选项卡

**「标注」** 选项卡提供标注数据的导入和导出：

| 按钮 | 功能 |
|------|------|
| 导入标注json | 导入已有的标注 JSON 文件，自动还原标注状态 |
| 导出标注json | 将当前标注数据导出为 JSON 文件 |

#### 导入标注 JSON

- 支持导入本工具导出的 JSON 标注文件
- 如果 JSON 文件位于 `labels/` 目录下，系统会自动查找 `steps/` 目录中的同名 STEP 文件并加载模型
- 导入后会自动还原所有特征名称、标注记录、底面信息

#### 目录结构约定

```
项目文件夹/
├── steps/          ← 存放 STEP 模型文件
│   └── model.step
└── labels/         ← 存放标注 JSON 文件
    └── model.json
```

### 3.4 特征名称面板（左侧）

管理当前可用的特征名称列表。

| 操作 | 说明 |
|------|------|
| 输入框 + 「添加」 | 添加新的特征名称（不可重复） |
| 列表点击 | 选中当前标注使用的特征名称 |
| 「移除」 | 删除选中的特征名称 |

> 系统会为每个特征名称自动分配一个唯一的数字 ID，导出时用于标识类别。

### 3.5 标注特征面板（右侧）

标注操作的主交互面板，包含按钮区和列表区。

#### 按钮说明

6 个按钮以 2×3 网格排列，统一尺寸：

| 按钮 | 作用 | 使用方法 |
|------|------|----------|
| 标注 | 选中多个面 → 归为同一实例（一个特征组） | 先在左侧面板选择特征名称，再在 3D 视图中选中多个面，点击后所有面归为一行 |
| 标注底面 | 选中 1 个面 → 匹配到已有标注行，标记为底面 | 在 3D 视图中选中一个已标注过的面，点击后自动匹配到对应标注行的底面列 |
| 高亮 | 选中列表行 → 在 3D 视图中高亮对应面 | 先在列表中选中一行或多行（Ctrl 多选），点击后对应面在 3D 视图中高亮显示 |
| 批量标注 | 选中多个面 → 每个面各自一个实例 | 先在左侧面板选择特征名称，再在 3D 视图中选中多个面，点击后每个面各占一行 |
| 批量标注底面 | 选中多个面 → 批量匹配底面 | 在 3D 视图中选中多个已标注过的面，点击后每个面自动匹配到对应标注行的底面列 |
| 移除 | 选中列表行 → 删除，清除相关数据 | 先在列表中选中一行或多行（Ctrl 多选），点击后删除并同步清理底面、实例等关联数据 |

#### 标注列表

列表显示所有已标注的特征，包含 5 列：

| 列 | 说明 |
|----|------|
| 特征 | 标注的特征名称 |
| 对象 | 所属 CAD 对象名称 |
| 面ID | 被标注的面的 ID（多个用逗号分隔） |
| 底面 | 被标记为底面的面 ID（多个用逗号分隔） |
| [+] | 快捷操作按钮 |

#### 列表交互

- **点击 [+] 按钮** → 弹出菜单，可选择"添加到面ID"或"添加到底面"
  - 先在 3D 视图中选中要追加的面，再点击 [+]，菜单会出现在鼠标点击位置
  - 追加面ID：面归入当前行的实例组
  - 追加底面：面标记为当前行的底面，同时自动同步到面ID列

## 四、标注操作指南

### 4.1 单次标注（多个面归为同一实例）

适用场景：标注一个完整的特征（如一个圆角包含多个面）。

1. 在左侧面板选择特征名称（如"圆角"）
2. 在 3D 视图中选中该特征的所有面
3. 点击 **「标注」** 按钮
4. 右侧列表新增一行，所有选中面显示在"面ID"列中

### 4.2 批量标注（每个面独立实例）

适用场景：快速标注多个独立的同类特征（如多个独立的圆角）。

1. 在左侧面板选择特征名称
2. 在 3D 视图中选中多个面
3. 点击 **「批量标注」** 按钮
4. 右侧列表为每个面各新增一行

### 4.3 标注底面

适用场景：为盲孔、槽等特征的底面单独标记。

**单个底面：**
1. 在 3D 视图中选中一个底面
2. 点击 **「标注底面」** 按钮
3. 系统自动匹配该面所在的标注行，将面 ID 添加到底面列

**批量底面：**
1. 在 3D 视图中选中多个底面
2. 点击 **「批量标注底面」** 按钮
3. 系统自动将每个面匹配到对应的标注行

### 4.4 追加面到已有标注

适用场景：漏选了面，需要补充到已有的标注行。

1. 先在 3D 视图中选中要追加的面
2. 在列表中点击目标行的 **[+]** 按钮
3. 在弹出的菜单中选择 **"添加到面ID"** 或 **"添加到底面"**
4. 面将被追加到对应列，数据同步更新

### 4.5 移除标注

1. 在列表中选中一行或多行（按住 Ctrl 多选）
2. 点击 **「移除」** 按钮
3. 选中的标注行被删除，相关数据同步清理

### 4.6 撤销操作

- 按下 **Ctrl + Z** 可撤销最近一次操作
- 最多支持撤销 **50 步**
- 支持撤销的操作：标注、批量标注、标注底面、批量标注底面、移除、[+] 追加面

---

## 五、自动保存

- 系统每 **2 分钟** 自动保存一次标注进度
- 首次自动保存时，会在 STEP 文件同目录下生成 `文件名_auto_save.json`
- 手动导出后，自动保存路径更新为导出文件路径
- 手动导出时会自动删除之前的临时自动保存文件

## 六、导出数据格式说明

导出的 JSON 文件包含以下字段：

```json
{
  "source_file": "模型文件路径",
  "feature_mapping": {
    "圆角": 1,
    "盲孔": 2
  },
  "seg": {
    "0": 1,
    "1": 1,
    "2": 2
  },
  "inst": [
    [1, 1, 0],
    [1, 1, 0],
    [0, 0, 1]
  ],
  "bottom": {
    "0": 0,
    "1": 0,
    "2": 1
  }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `source_file` | string | 源 STEP 文件路径 |
| `feature_mapping` | object | 特征名称到类别 ID 的映射表 |
| `seg` | object | 语义分割：面 ID → 类别 ID（未标注的面类别为 0） |
| `inst` | array | 实例分割矩阵：N×N 矩阵，`inst[i][j]=1` 表示面 i 和面 j 属于同一实例 |
| `bottom` | object | 底面标记：面 ID → 1（是底面）/ 0（不是底面） |

## 八、常见问题

### Q：导入模型后 3D 视图空白？

请确认 `config/system_config.json` 中的 `dllPath` 指向正确的 NCTI SDK 路径，且所需 DLL 文件存在。

### Q：如何选择多个面？

在「选择/显示」选项卡中确保「面」选择模式已勾选，然后在 3D 视图中依次点击多个面。

### Q：标注错了怎么修改？

- 按 Ctrl + Z 撤销最近的操作
- 或在列表中选中错误的行，点击「移除」按钮删除

### Q：导入标注 JSON 后看不到模型？

确保 JSON 文件放在 `labels/` 目录下，对应的 STEP 文件放在同级 `steps/` 目录下，且文件名一致。

### Q：导出的 JSON 中 inst 矩阵太大？

inst 矩阵大小取决于模型中最大面 ID。如果面 ID 分布稀疏，矩阵中会有大量 0 值。这是正常现象，不影响数据正确性。

## 九、配置说明

编辑 `config/system_config.json` 可修改以下配置：

| 配置项 | 说明 |
|--------|------|
| `dllPath` | NCTI SDK 所在目录路径 |
| `addKernelPath` | 附加内核搜索路径（如 OCC） |
| `loadDLL` | 启动时需要加载的 DLL 列表 |

配置文件示例见 `config/system_config.json`。
