## 草图识别方向澄清（重要，避免实习产出误对标）
- 用户痛点：草图图片让 LLM/VLM 识别，结构/尺寸误差大，且自然语言描述不出来（language head 有损）。
- **CADSmith(arXiv:2603.26512) 真实做法**：输入是纯自然语言文本（非图像）；"程序化几何验证"=OCCT 内核量 B-rep；VLM Judge=看 VTK 渲染三视图；双嵌套循环+RAG 非微调。**它不用 SAM/Hough/OCR 读草图图像**——之前对话里把 CV 感知说成 CADSmith 做法是张冠李戴，已纠正。
- 关键定位：CV/几何感知层（图像→SketchSpec）是本项目相对 CADSmith 的**增量贡献**，因输入模态不同（图 vs 文本）。
- 产出文档：`docs/sketch-perception-design.md`（新增感知层：CV/几何+OCR 出数值真值，VLM 仅编排/兜底，尺度标定 px→mm，约束几何推导，接入现有 Transpiler+verify_sketch 闭环）。现有 `docs/sketch-transpile-verify-design.md` 已加交叉引用。
- 设计原则：CV/几何=数值真值来源，LLM/VLM=编排者，最终产出必须是结构化 SketchSpec 而非自然语言。

## 草图识别 Related Work 调研（2026-07-21，已写入 docs/sketch-perception-design.md 第10节）
