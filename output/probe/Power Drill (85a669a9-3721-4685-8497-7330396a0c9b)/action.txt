---  SECTION 1 – Create Main Body Shell  ---
Create primitive cuboid with size 0.055×0.055×0.08 m and name it body_shell_base.
Rotate body_shell_base so its +Z axis aligns +Z (world).
Anchor body_shell_base to drill_root.center.
Then move by offset(0, 0, 0).
Create primitive cylinder with size Ø0.045×0.12 m and name it handle_base.
Rotate handle_base so its +Z axis aligns +Z (world).
Align handle_base.center to body_shell_base.center.
Then move by offset(0, -0.06, 0).
Boolean-union handle_base from body_shell_base; discard handle_base.
Create primitive cylinder with size Ø0.048×0.10 m and name it grip_cutter.
Rotate grip_cutter so its +Z axis aligns +Z (world).
Align grip_cutter.center to body_shell_base.left_face.
Then move by offset(-0.0015, 0, 0).
Boolean-subtract grip_cutter from body_shell_base; discard grip_cutter.
Create primitive cuboid with size 0.048×0.048×0.002 m and name it grip_overlay.
Rotate grip_overlay so its +Z axis aligns +Z (world).
Align grip_overlay.left_face to body_shell_base.left_face.
Then move by offset(0.001, 0, 0).
Boolean-union grip_overlay from body_shell_base; discard grip_overlay.
Create primitive cuboid with size 0.055×0.055×0.06 m and name it head_casing.
Rotate head_casing so its +Z axis aligns +Z (world).
Align head_casing.right_face to body_shell_base.right_face.
Boolean-union head_casing from body_shell_base; discard head_casing.
Bevel body_shell_base.edges with radius 0.005 m, segments 4.
Assembly guideline satisfied.
Stage 1 complete.
