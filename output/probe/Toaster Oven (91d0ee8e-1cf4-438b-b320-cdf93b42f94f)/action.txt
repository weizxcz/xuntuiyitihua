BLOCK 0 – Scene Reset & Units
────────────────────────────────────────────────────────
Delete every existing object to start from a clean scene.
Set the length unit to **metres**.

BLOCK 2 – Stage-by-Stage Operations
────────────────────────────────────────────────────────

---  SECTION 1 – Create Body Group (Chassis & Top Cover)  ---
Create primitive cuboid with size 0.40×0.30×0.25 m and name it chassis.
Rotate chassis so its +Z axis aligns +Z (world).
Anchor chassis to world origin.
Then move by offset(0, 0.15, 0).

Create primitive cuboid with size 0.40×0.30×0.005 m and name it top_cover.
Rotate top_cover so its +Z axis aligns +Z (world).
Align top_cover.-Z_face to chassis.+Z_face.
Then move by offset(0, 0, 0.005).

Stage 1 complete.

---  SECTION 2 – Create Door Assembly (Frame, Glass, Handle, Hinge)  ---
Create primitive cuboid with size 0.38×0.28×0.02 m and name it door_frame.
Rotate door_frame so its +Z axis aligns +Z (world).
Align door_frame.center to chassis.+X_face.center.
Then move by offset(0, 0, 0.002).

Create primitive cuboid with size 0.30×0.20×0.004 m and name it door_glass.
Rotate door_glass so its +Z axis aligns +Z (world).
Align door_glass.center to door_frame.center.
Then move by offset(0, 0, 0.001).

Create primitive cylinder with diameter 0.01 m and length 0.25 m and name it door_handle.
Rotate door_handle so its +Z axis aligns +X (world).
Align door_handle.center to door_frame.-Z_face.center.
Then move by offset(0, 0, 0.015).

Create primitive cuboid with size 0.02×0.02×0.01 m and name it door_hinge.
Rotate door_hinge so its +Z axis aligns +Z (world).
Align door_hinge.center to door_frame.+Z_face.center.
Then move by offset(0, 0, 0.001).

Stage 2 complete.
