BLOCK 0 – Scene Reset & Units
────────────────────────────────────────────────────────
Delete every existing object to start from a clean scene.
Set the length unit to **metres**.

---

BLOCK 1 – Materials
────────────────────────────────────────────────────────
Define material mat_concrete_grey; diffuse_color = (0.75,0.75,0.75,1.0).
Define material mat_tile_white; diffuse_color = (0.95,0.95,0.95,1.0).
Define material mat_tile_black; diffuse_color = (0.10,0.10,0.10,1.0).

---

BLOCK 2 – Stage-by-Stage Operations
────────────────────────────────────────────────────────

---  SECTION 1 – Create Floor Base Platform  ---
Create primitive cuboid with size 10×10×0.1 m and name it root.
Rotate root so its +Z axis aligns +Z (world).
Move root by offset(0,0,0).
Stage 1 complete.

---  SECTION 2 – Create Pattern Layer Grid  ---
For r in 0…19 and c in 0…19:
  Create primitive cuboid with size 0.5×0.5×0.02 m and name it tile_base_r_c.
  Rotate tile_base_r_c so its +Z axis aligns +Z (world).
  Anchor tile_base_r_c to root.top_face.
  Then offset(0.25 + c·0.5, 0.25 + r·0.5, 0.01).

  Create primitive cylinder with Ø0.2×0.02 m and name it tile_center_r_c.
  Rotate tile_center_r_c so its +Z axis aligns +Z (world).
  Anchor tile_center_r_c to tile_base_r_c.top_face.
  Then offset(0,0,0).

  Create primitive cuboid with size 0.1×0.1×0.02 m and name it tile_corner_r_c.
  Rotate tile_corner_r_c so its +Z axis aligns +Z (world).
  Anchor tile_corner_r_c to tile_base_r_c.top_face.
  Then offset(0.2, 0.2, 0).

Stage 2 complete.

All stages complete.
