BLOCK 0 – Scene Reset & Units
────────────────────────────────────────────────────────
Delete every existing object to start from a clean scene.
Set the length unit to **metres**.

---

BLOCK 1 – Materials
────────────────────────────────────────────────────────
Define material fabric_dark_blue; diffuse_color = (0.05,0.10,0.25,1.0).
Define material fabric_lining; diffuse_color = (0.90,0.90,0.90,1.0).

---

BLOCK 2 – Stage-by-Stage Operations
────────────────────────────────────────────────────────

---  SECTION 1 – Create tie_body (Main Blade)  ---
Create primitive cuboid with size 0.080×0.350×0.002 m and name it blade_main.
Rotate blade_main so its +Z axis aligns +Z (world).
Anchor blade_main to world origin.
Then move by offset(0, 0, 0).

Create primitive cuboid with size 0.080×0.120×0.002 m and name it blade_tip.
Rotate blade_tip so its +Z axis aligns +Z (world).
Anchor blade_tip to blade_main.-Y_face (bottom edge of main blade).
Align blade_tip.-Y_face to blade_main.-Y_face.
Then move by offset(0, -0.235, 0).
Bevel blade_tip.-Y_edge_set with radius 0.01 m, segments 4.
Assembly guideline satisfied.
Stage 1 complete.

---  SECTION 2 – Create tie_lining (Lining Fabric)  ---
Create primitive cuboid with size 0.076×0.340×0.001 m and name it lining_main.
Rotate lining_main so its +Z axis aligns +Z (world).
Anchor lining_main to blade_main.+Z_face (front face of main blade).
Align lining_main.-Z_face to blade_main.+Z_face.
Then move by offset(0, 0, 0).

Create primitive cuboid with size 0.076×0.110×0.001 m and name it lining_tip.
Rotate lining_tip so its +Z axis aligns +Z (world).
Anchor lining_tip to blade_tip.+Z_face (front face of tip).
Align lining_tip.-Z_face to blade_tip.+Z_face.
Then move by offset(0, -0.230, 0).
Stage 2 complete.

---  SECTION 3 – Create tie_knot (Knot & Drape)  ---
Create primitive cuboid with size 0.060×0.060×0.060 m and name it knot_body.
Rotate knot_body so its +Z axis aligns +Z (world).
Anchor knot_body to world origin.
Then move by offset(0, 0.150, 0).

Create primitive cuboid with size 0.080×0.200×0.002 m and name it knot_drape.
Rotate knot_drape so its +Z axis aligns +Z (world).
Anchor knot_drape to knot_body.-Y_face (bottom face of knot).
Align knot_drape.+Y_face to knot_body.-Y_face.
Then move by offset(0, 0.050, 0).
Stage 3 complete.

---  SECTION 4 – Final Assembly  ---
Align tie_lining to tie_body.
Align knot_body to tie_body.
Align knot_drape to knot_body.
Assembly guideline satisfied.
All stages complete.
