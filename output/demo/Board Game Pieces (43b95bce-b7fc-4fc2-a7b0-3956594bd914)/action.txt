BLOCK 0 – Scene Reset & Units
────────────────────────────────────────────────────────
Delete every existing object to start from a clean scene.
Set the length unit to **metres**.

BLOCK 1 – Materials
────────────────────────────────────────────────────────
Define material mat_blue; diffuse_color = (0.2,0.4,0.8,1.0).
Define material mat_green; diffuse_color = (0.2,0.7,0.2,1.0).
Define material mat_red; diffuse_color = (0.8,0.2,0.2,1.0).

BLOCK 2 – Stage-by-Stage Operations
────────────────────────────────────────────────────────

---  SECTION 1 – Create Blue Pawn Piece  ---
Create primitive cylinder with diameter 0.02 m and height 0.005 m and name it base_cylinder.
Rotate base_cylinder so its +Z axis aligns +Z (world).
Anchor base_cylinder to root.origin.
Then move by offset(0,0,0).

Create primitive cylinder with diameter 0.015 m and height 0.02 m and name it body_cylinder.
Rotate body_cylinder so its +Z axis aligns +Z (world).
Align body_cylinder.bottom_face to base_cylinder.top_face.
Then move by offset(0,0,0.0125).

Create primitive sphere with diameter 0.012 m and name it head_sphere.
Rotate head_sphere so its +Z axis aligns +Z (world).
Align head_sphere.bottom to body_cylinder.top.
Then move by offset(0,0,0.0275).

Boolean-union base_cylinder, body_cylinder, and head_sphere; keep union result named blue_piece.
Rotate blue_piece so its +Z axis aligns +Z (world).
Anchor blue_piece to root.origin.
Then move by offset(0.05, 0.05, 0.01).
Apply material mat_blue to blue_piece.
Assembly guideline satisfied.
Stage 1 complete.
