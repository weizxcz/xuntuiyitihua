Delete every existing object to start from a clean scene.

BLOCK 2 – Stage-by-Stage Operations
────────────────────────────────────────────────────────

---  SECTION 1 – Create Outer Casing  ---
Create primitive cuboid with size 0.520×0.400×0.300 m and name it main_body_shell.
Rotate main_body_shell so its +Z axis aligns +Z (world).
Move main_body_shell to pos=(0, 0.150, 0).

Create primitive cuboid with size 0.520×0.400×0.005 m and name it top_panel.
Rotate top_panel so its +Z axis aligns +Z (world).
Align top_panel.bottom_face to main_body_shell.top_face.
Then move by offset(0,0,0).

Create primitive cuboid with size 0.520×0.300×0.005 m and name it back_panel.
Rotate back_panel so its +Z axis aligns +Z (world).
Align back_panel.front_face to main_body_shell.back_face.
Then move by offset(0,0,0).

Stage 1 complete.

---  SECTION 2 – Create Interior Assembly  ---
Create primitive cuboid with size 0.480×0.360×0.280 m and name it cavity_inner.
Rotate cavity_inner so its +Z axis aligns +Z (world).
Move cavity_inner to pos=(0, 0.140, 0.010).

Create primitive cylinder with Ø0.250×0.005 m and name it turntable.
Rotate turntable so its +Z axis aligns +Z (world).
Align turntable.center to cavity_inner.center.
Align turntable.bottom_face to cavity_inner.bottom_face.
Then move by offset(0,0,0.005).

Create primitive cylinder with Ø0.050×0.040 m and name it turntable_motor.
Rotate turntable_motor so its +Z axis aligns +Z (world).
Align turntable_motor.center to cavity_inner.center.
Align turntable_motor.bottom_face to cavity_inner.bottom_face.
Then move by offset(0,0,0).

Stage 2 complete.

---  SECTION 3 – Create Door Assembly  ---

Align door_frame.front_face to main_body_shell.front_face.
Then move by offset(0,0,0.010).

Align door_window.center to door_frame.center.
Align door_window.back_face to door_frame.front_face.

Stage 3 complete.

---  SECTION 4 – Create Control Panel  ---
