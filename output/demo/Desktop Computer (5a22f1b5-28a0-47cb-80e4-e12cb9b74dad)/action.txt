BLOCK 0 – Scene Reset & Units
────────────────────────────────────────────────────────
Delete every existing object to start from a clean scene.
Set the length unit to **metres**.

---

BLOCK 1 – Materials
────────────────────────────────────────────────────────
Define material mat_black_plastic; diffuse_color = (0.10,0.10,0.10,1.00).
Define material mat_grey_plastic; diffuse_color = (0.50,0.50,0.50,1.00).
Define material mat_screen_black; diffuse_color = (0.05,0.05,0.05,1.00).
Define material mat_screen_glow; diffuse_color = (0.20,0.40,0.80,1.00).

---

BLOCK 2 – Stage-by-Stage Operations
────────────────────────────────────────────────────────

---  SECTION 1 – Create Base Platform  ---
Create primitive cuboid with size 1.2×0.6×0.02 m and name it desk_surface.
Rotate desk_surface so its +Z axis aligns +Z (world).
Move desk_surface to pos=(0,0,0).
Stage 1 complete.

---  SECTION 2 – Create Monitor Components  ---
Create primitive cuboid with size 0.60×0.35×0.02 m and name it monitor_bezel.
Rotate monitor_bezel so its +Z axis aligns +Z (world).
Move monitor_bezel to pos=(0, -0.2, 0.35).

Create primitive cuboid with size 0.56×0.31×0.005 m and name it monitor_screen.
Rotate monitor_screen so its +Z axis aligns +Z (world).
Move monitor_screen to pos=(0, -0.185, 0.35).
Stage 2 complete.

---  SECTION 3 – Create CPU Components  ---
Create primitive cuboid with size 0.20×0.45×0.40 m and name it cpu_tower.
Rotate cpu_tower so its +Z axis aligns +Z (world).
Move cpu_tower to pos=(-0.35, -0.1, 0.225).

Create primitive cuboid with size 0.02×0.01×0.005 m and name it cpu_buttons.
Rotate cpu_buttons so its +Z axis aligns +Z (world).
Move cpu_buttons to pos=(-0.25, -0.1, 0.425).

Create primitive cuboid with size 0.04×0.01×0.005 m and name it cpu_ports.
Rotate cpu_ports so its +Z axis aligns +Z (world).
Move cpu_ports to pos=(-0.25, -0.1, 0.415).
Stage 3 complete.

---  SECTION 4 – Create Peripherals  ---
Create primitive cuboid with size 0.45×0.15×0.02 m and name it keyboard.
Rotate keyboard so its +Z axis aligns +Z (world).
Move keyboard to pos=(0, 0.15, 0.01).

Create primitive cuboid with size 0.06×0.10×0.03 m and name it mouse.
Rotate mouse so its +Z axis aligns +Z (world).
Move mouse to pos=(0.25, 0.15, 0.015).
Stage 4 complete.

---  SECTION 5 – Assemble Monitor  ---
Align monitor_screen.front_face to monitor_bezel.back_face.
Then offset(0,0,0.002).
Assembly guideline satisfied.
Stage 5 complete.

---  SECTION 6 – Assemble CPU  ---
Align cpu_buttons.center to cpu_tower.front_face.center.
Then offset(0,0,0.002).
Align cpu_ports.center to cpu_tower.front_face.center.
Then offset(0,0,0.002).
Assembly guideline satisfied.
Stage 6 complete.

All stages complete.
