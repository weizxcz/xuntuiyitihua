BLOCK 0 – Scene Reset & Units
────────────────────────────────────────────────────────
Delete every existing object to start from a clean scene.
Set the length unit to **metres**.

BLOCK 2 – Stage-by-Stage Operations
────────────────────────────────────────────────────────

---  SECTION 1 – Create tile_unit (Primary Structure) ---
Create primitive cuboid with size 0.2×0.2×0.01 m and name it square_base.
Rotate square_base so its +Z axis aligns +Z (world).
Anchor square_base to world origin.
Then move by offset(0,0,0).

Create primitive triangle_prism with size 0.1×0.1×0.01 m and name it triangle_A.
Rotate triangle_A so its +Z axis aligns +Z (world).
Align triangle_A.bottom_right to square_base.top_right.
Then move by offset(0.1,0.1,0).

Create primitive triangle_prism with size 0.1×0.1×0.01 m and name it triangle_B.
Rotate triangle_B so its +Z axis aligns +Z (world).
Align triangle_B.bottom_left to square_base.top_left.
Then move by offset(-0.1,0.1,0).

Create primitive triangle_prism with size 0.1×0.1×0.01 m and name it triangle_C.

Align triangle_C.top_left to square_base.bottom_left.

Create primitive triangle_prism with size 0.1×0.1×0.01 m and name it triangle_D.
