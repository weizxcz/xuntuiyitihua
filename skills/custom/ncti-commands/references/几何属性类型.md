## 获取对象的几何属性

**类型：** 基础命令

**说明：** 根据实体对象名称，返回其几何属性

**示例：**

```python
doc.RunCommand("cmd_ncti_create_box", "b", 6, 6, 6)
prorp = NCTI.BodyProp(doc, "b")
# # 线长，对于线有效
# print(prorp.WireLength) 
# 表面积，对于面或者实体有效
print(prorp.Area)
# 体积，对于实体有效
print(prorp.Volumn)
# 重心
print(prorp.gravityCenterX) 
print(prorp.gravityCenterY)
print(prorp.gravityCenterZ)
# 惯性矩
print(prorp.inertiaMatrix00)
print(prorp.inertiaMatrix01)
print(prorp.inertiaMatrix02)
print(prorp.inertiaMatrix10)
print(prorp.inertiaMatrix11)
print(prorp.inertiaMatrix12)
print(prorp.inertiaMatrix20)
print(prorp.inertiaMatrix21)
print(prorp.inertiaMatrix22)
# 静态惯性矩
print(prorp.Ix)
print(prorp.Iy)
print(prorp.Iz)
# 主力矩
print(prorp.Ixx)
print(prorp.Iyy)
print(prorp.Izz)
# 主回转半径
print(prorp.Rxx)
print(prorp.Ryy)
print(prorp.Rzz)
```
