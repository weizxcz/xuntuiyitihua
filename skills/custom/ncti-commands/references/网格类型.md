# 网格类型参考文档

共 9 个命令

---

## 显示网格质量界面

**类型：** 建模命令

**说明：** 显示网格质量界面

**示例：**

```python
#此处需创建面网格或体网格，并选中其实体对象
sel = NCTI.SelectionManager(doc)
boxMesh = NCTI.GridMesh(doc, sel.ObjectNames[0])
print(boxMesh)
mode = 4
meshValuVec = boxMesh.GetMeshClassifyValues(mode)
boxMesh.ShowMeshClassifyDlg(mode, meshValuVec)
```

## 获取指定顶点的位置


## 获取网格

**类型：** 建模命令

**说明：** 通过对象名获取网格

**示例：**

