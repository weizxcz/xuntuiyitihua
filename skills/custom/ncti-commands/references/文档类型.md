## 3D约束查询

**类型：** 基础命令

**说明：** 3D约束查询

**示例：**

```python

#line2

doc.RunCommand("cmd_ncti_create_dcm3_line", "dcm_line2", "dcmsys", NCTI.Point(0,0.,0), NCTI.Vector(1,0,0), "line2")

doc.RunCommand("cmd_ncti_dcm3_addd", "dcmsys", "dcm_par", "dcm_cyd1", "dcm_line2")
```

**示例：**

```python
doc.Clear()
doc.ResetCaseResult()
```

```python
import os
```
```python
partitionTag1 = doc.PartitionCreate()
```
```python
doc.PartitionSetCurrent(partitionTag1)
pmark = doc.PartitionMakePmark2(partitionTag1)

filepath = doc.GetWorkingPath() + '/partition_transmit_file.P_B'
if os.path.exists(filepath):
    os.remove(filepath)
doc.PartitionTransmit(partitionTag1, filepath, 3)
```

```python
doc.RunCommand("cmd_ncti_create_dcm_line", "DlineX", "dcmsys1", pt1, xdir, "BlineX")
```

## 返回约束自由度信息

**类型：** 约束命令

**说明：** 根据约束系统对象名称，用于返回约束自由度信息

**示例：**

```python
pt1 = NCTI.Point(10, 10,0)
pt2 = NCTI.Point(10, 20,0)
xdir = NCTI.Vector(1,0,0)
doc.RunCommand("cmd_ncti_create_line","Bline1", pt1, xdir)
doc.RunCommand("cmd_ncti_create_vertex","Bpt1", pt2)
doc.RunCommand("cmd_ncti_create_dim_sys", "dcmsys1")
doc.RunCommand("cmd_ncti_create_dcm_line", "Dline1", "dcmsys1", pt1, xdir, "Bline1")
doc.RunCommand("cmd_ncti_create_dcm_point", "Dpt1", "dcmsys1", pt2, "Bpt1")
doc.RunCommand("cmd_ncti_create_dcm_dimension", "coi", DCM_COINCIDENT, 0)
doc.RunCommand("cmd_ncti_dcm_addd", "dcmsys1", "coi", "Dpt1", "Dline1")
doc.RunCommand("cmd_ncti_dcm_evaluate", "dcmsys1")
con_bal_res = doc.dcm_constraint_balance("dcmsys1")
print(con_bal_res)
res = con_bal_res[1] - con_bal_res[2] - con_bal_res[3]
if res < 0:
    print(f"Overconstrained by {res}")
elif res == 0:
    print("Right number of dimensions")
else:
    print(f"Underconstrained by {res}")
```
