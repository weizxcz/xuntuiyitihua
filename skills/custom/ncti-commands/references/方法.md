## 初始化平台

**示例：**

```python
dllpath = "D:\\YanHe_PreCAE"
NCTI.Init(dllpath)
```

## 定制多端参数对话框

**类型：** 基础命令

**说明：** 动态定义参数对话框用于获取属性值、对象名称以及操作文件

**示例：**

```python
#定义参数及初始化
#数值类型
cy1_r = 3.5
cy1_h = 8
cy1_pt = NCTI.Point(0, 4.8, 0)
cy1_vec = NCTI.Vector(0, 1, 0)

#对象类型
sel_obj = {"sel" : ["objName1", "objName2"]}

#文件类型
sel_fl = {"selFolder": "D:/save"}
sel_f2 = {"saveFile": "D://save//test_save_stp", "filter": "Files(*.stp)"}
sel_f3 = {"selFiles": ["D:\save\test.stp", "D:\save\f1.igs"], "filter": "Files(*.igs *.stp)"}

res = NCTI.Dialog(-1, "自定义参数窗口标题",
"圆柱半径", cy1_r,
"圆柱高度", cy1_h,
"圆柱上底面圆心", cy1_pt,
"圆柱底面法向", cy1_vec,
"选择文件夹", sel_fl,
"保存文件", sel_f2,
"选择文件", sel_f3,
"选取实体对象", sel_obj)

#确认后可输出
print(res)
```

## 获得python模块的版本信息

**类型：** 基础命令

**说明：** 获得python模块的版本信息

**示例：**

```python
# 在python编译器中，输出ncti_python的版本信息
ver = NCTI.GetVersion()
print(ver)
```
