## 草图 Agent 部署架构确认（用户口述，关键）
- 用户确认：AI 生成的草图脚本需要**复制到团队另外的内核软件里才能渲染**。因此 `ncti_python` 绑定无法 headless 执行是**架构使然**，不是我们探测到的临时坑。
- 含义：① `run_sketch_pipeline` 的 `kernel` 字段维持 `skipped` 是**正确行为**（非 bug）；② 真实深验（DOF/冲突读回）只能发生在宿主应用内，或依赖内核团队提供无 GUI 的 headless 引擎入口（路径 A）；③ 已写好的 `set_kernel_runtime` 接缝仍是正确的集成点，但其实现必须是「把脚本喂进宿主应用再取回结果」，而非裸 `Document()`。
- 若无 headless 入口，产品 MVP 边界即为「浅层验证 + 人工在软件内渲染确认」。这与 2026-07-21 的 option (c) 探针结论（§5.3）完全一致。
