# Split_Assembly_and_Detect_blind_hole 版本变更说明

## 本次提交概述

本次更新将 `Split_Assembly_and_Detect_blind_hole` 整理为可独立打包上传服务器运行的版本。目录内已移除旧版盲孔识别脚本，只保留当前使用的盲孔 v15_23 和沉头孔 v15 识别脚本，并同步修正 pipeline 的导入关系和 JSON 输出格式。,同时更新最新版本的solid.db，重点更新其中的盲孔和沉头孔相关字段

## 文件结构变化

- 删除旧版盲孔识别脚本：
  - `blind_hole/detect_blind_holes_and_export_stp_v15_15.py`
- 新增当前盲孔识别脚本：
  - `blind_hole/detect_blind_holes_and_export_stp_v15_23.py`
- 新增沉头孔/沉孔识别脚本：
  - `countersunk_hole/detect_countersunk_holes_and_export_stp_v15.py`
- 更新说明文档：
  - `README.md`
-更新solid_info.db：
  - `solid_info.db`

## 盲孔识别脚本更新说明

盲孔识别入口由旧版 v15_15 更新为 v15_23，相关导入已同步修改：

- `blind_hole/pipeline_core.py`
- `function/on_find_blind_hole_stp.py`
- `optimized_pipeline/fast_blindhole_pipeline.py`

v15_23 相比旧版主要增强点：

- 增强复杂盲孔识别能力，支持更多非标准 STEP 建模形态。
- 增加拆分圆柱壁盲孔补充规则，可识别圆柱孔壁被多个 `CYLINDRICAL_SURFACE` 面拆开的情况。
- 增加局部/共享底面处理能力，对共享平面底、复合底面等情况生成更稳定的底面标注。
- 增强入口倒角面处理，导出和标注时可包含入口倒角相关面。
- 增加广义截断圆柱、变深截断圆柱等补充规则，用于覆盖部分复杂盲孔形态。
- 导出 STP 时保留 exact-face 思路，尽量只导出识别到的盲孔相关面，便于可视化检查。

盲孔训练类别保持不变：

- `feature_type = "blind_hole"`
- `category_id = 12`

## 沉头孔脚本说明

新增 `countersunk_hole/detect_countersunk_holes_and_export_stp_v15.py`，用于识别沉头孔和沉孔两类结构。

基本能力：

- 解析 STEP 几何实体和面邻接关系。
- 识别 countersink 类型沉头孔。
- 识别 counterbore 类型沉孔。
- 输出识别到的孔特征面集合。
- 支持将沉头孔/沉孔面统一映射为训练 JSON 中的标注面。

当前 `Split_Assembly_and_Detect_blind_hole` 目录内主要运行入口仍是盲孔 pipeline；沉头孔脚本已随包携带，便于后续扩展沉头孔批处理流程。

## JSON 生成格式变化

旧格式最外层是对象：

```json
{
  "seg": {},
  "inst": [],
  "bottom": {}
}
```

新格式最外层统一改为数组：

```json
[
  {
    "seg": {},
    "inst": [],
    "bottom": {}
  }
]
```

此次修改没有改变 `seg`、`inst`、`bottom`、`feature_mapping` 等内部字段含义，只改变最外层容器，保证生成结果符合训练数据标准格式。

相关修改点：

- `blind_hole/pipeline_core.py`
  - 新增 `ensure_training_label_json_list()`
  - 本地保存 JSON 和调用后端 `/label/save_json` 时都会自动保证顶层为数组。
- `optimized_pipeline/fast_blindhole_pipeline.py`
  - 保存 JSON 时显式使用标准数组格式。

## 提交说明可用摘要

本次提交将可打包运行目录升级为 v15_23 盲孔识别版本，移除旧 v15_15 脚本和非必要独立工具脚本，新增沉头孔/沉孔 v15 识别脚本，并统一训练 JSON 输出为顶层数组格式 `[{...}]`。
